## practice: apache

The following exercises can be done on a virtual machine with either a Debian-based or Enterprise Linux based distribution.

1. Install Apache and test that it works

2. Browse the Apache HTML manual and look up the directives that were used in this chapter.

3. Create three virtual hosts that listen on ports 8472, 31337 and 1201. Test that it all works.

4. Create three named virtual hosts `startrek.local`, `starwars.local` and `stargate.local`, and add some content. Test that it all works.

5. Create a virtual hosts that listens on *another ip-address*.

6. Protect one of your websites with a user/password combo.
